# HTMX update procedure

Download `https://unpkg.com/htmx.org@2.0.10/dist/htmx.min.js` and the upstream
`LICENSE`, verify the SHA-256 values below, then replace the embedded files
without modification. This release is intentionally pinned to 2.0.10 and uses
no extensions or CDN.
